# 大疆无人机倾斜摄影数据提取建筑障碍物入库及航线规划应用技术方案

> 版本：v1.0　|　适用环境：Windows + WebODM 2.9.6 + QGIS/OSGeo4W + PostgreSQL 17 + PostGIS 3.6
> 目标：从大疆无人机倾斜航飞成果中提取建筑/障碍物（轮廓+高度+类型），入库 PostgreSQL，用于无人机航线规划的净空避障与三维可视化叠加。

---

## 一、项目背景与目标

### 1.1 背景
无人机低空巡检/作业中，航线规划必须避开建筑物、树木、电线杆、塔吊等障碍物，否则存在飞行碰撞风险。传统做法依赖人工目视勾绘，工作量大、易漏判、难更新。

### 1.2 目标
- 从大疆倾斜摄影成果（正射 DOM、倾斜模型、点云）中**自动提取建筑障碍物**；
- 得到每个障碍物的**平面轮廓、相对高度、类型**；
- 入库 **PostgreSQL/PostGIS**，形成统一空间图层 `gis_obstacles`；
- 供**航线规划净空检查**、**避障**、**电子围栏联动**、**Cesium 三维叠加**使用。

### 1.3 成果与分工
| 数据 | 角色 | 解决什么问题 |
|---|---|---|
| 正射影像 DOM | 识别"是什么类型" | 地物分类、目视核对底图 |
| 倾斜模型 / DSM | 量"多高、多大轮廓" | 高度差分、三维展示 |
| 点云 LAS | 最准的高度/细小物 | 高精度障碍物、电力线/杆塔提取 |

## 二、总体技术架构

```
┌─────────────┐    ┌──────────────────┐    ┌──────────────────────┐
│ 大疆航飞数据 │ → │  WebODM 摄影测量  │ → │ DSM / DTM / DOM / 点云│
│ (多镜头影像) │    │  (空三+密集匹配)  │    └──────────┬───────────┘
└─────────────┘                                      │
                                                      ▼
                    ┌───────────────────────────────────────────┐
                    │  高度建模：nDSM = DSM − DTM（相对高度）      │
                    │  障碍物提取：阈值二值化 → 矢量化 → 分类       │
                    └───────────────────┬───────────────────────┘
                                        ▼
              ┌─────────────────────────────────────────────────┐
              │  PostgreSQL / PostGIS：gis_obstacles 空间表       │
              │  （footprint + height + obstacle_type + 索引）    │
              └───────────────────┬─────────────────────────────┘
                                  ▼
        ┌──────────────┬───────────────────┬─────────────────────┐
        ▼              ▼                   ▼                     ▼
   净空检查     航线避障约束        电子围栏联动        Cesium 三维叠加
  ST_3DIntersects  gis_astar_3d     gis_electric_fence  3D Tiles + 白膜
```

### 核心原理（一句话）
> 倾斜模型量高度（DSM−DTM=nDSM）→ 高于阈值圈成多边形 → 分类型存表 → 规划净空查询 → Cesium 叠加显示。

## 三、技术路线

1. **数据采集**：大疆无人机多镜头倾斜航飞，获取带 POS 坐标的影像。
2. **摄影测量处理（WebODM）**：空三解算 → 密集匹配 → 输出 DSM、DTM、DOM、点云。
3. **高度建模**：DSM − DTM（或点云滤波生成）得 nDSM 相对高度。
4. **障碍物提取**：nDSM 高度阈值二值化 → 矢量化 → 单体过滤 → 类型判定。
5. **空间入库**：raster2pgsql 栅格入库 + PostGIS 矢量化 → `gis_obstacles` 表。
6. **规划应用**：净空检查、避障约束、围栏联动。
7. **三维叠加**：坐标统一 4326，GeoJSON 白膜 / pg2b3dm 3D Tiles 叠加到倾斜模型。

## 四、详细技术方案

### 4.1 数据采集（大疆航飞）

- 载荷：大疆倾斜相机（多镜头：下视 + 前/后/左/右），或下视+少量倾斜。
- 航飞要求：保证**重叠度**（航向≥80%、旁向≥60%，倾斜模型建议更高），低空采集保证 DSM 分辨率。
- 成果：全部镜头影像（JPG）+ POS/坐标信息，整理到 `D:\drone_images`。

### 4.2 摄影测量处理（WebODM 2.9.6）

**WebODM**（OpenDroneMap 的 Web 界面）开源免费，可一站式产出 DSM/DTM/DOM/点云。

1. 启动：`docker run -d -p 3000:3000 -v D:/webodm:/webodm_data --name webodm opendronemap/webodm:2.9.6`，浏览器访问 `http://localhost:3000`。
2. 新建项目 → 新建任务 → 上传全部影像。
3. 关键参数：
   - 坐标系：带坐标自动识别；无坐标选 `EPSG:32649`（郑州 WGS84/UTM 49N）。
   - 输出：勾选 **DSM、DTM、正射影像、点云(LAS)**。
   - 分辨率：DSM ≤ 1m（越高越细，耗时越长）。
4. 处理完成后，Downloads 下载：
   - ✅ **点云(LAS)** → `odm_georeferenced_model.laz`（核心，能量高度）
   - ✅ **正射影像** → `orthophoto.tif`（识别类型 + 核对底图）
   - ✅（若有）**DSM、DTM** → `dsm.tif`、`dtm.tif`（可直接差分）

### 4.3 高度模型构建（nDSM）

**概念**：
- **DSM**（数字表面模型）= 地物顶部高程（含建筑、树顶）。
- **DTM**（数字地面模型）= 裸地面高程（滤波去掉地物）。
- **nDSM = DSM − DTM** = 每个像素"地物高出地面多少米"，是提取障碍物的依据。

**两条获取路径（二选一）**：

**路径 A：WebODM 直接给 DSM/DTM**（最省事）
```
直接下载 dsm.tif 和 dtm.tif，做差分即可。
```

**路径 B：用点云生成（无 DSM/DTM 时，精度更高）**
在 OSGeo4W Shell 中：
```bash
# ① DSM：全部点取最高（含楼顶）
pdal translate odm_georeferenced_model.laz dsm.tif -w gdal \
  --writers.gdal.resolution=0.5 --writers.gdal.output_type=max

# ② DTM：地面滤波只留地面点 → 裸地面（dem.json，见附录 A）
pdal pipeline dem.json
```

**差分得到 nDSM**：
```bash
gdal_calc.py -A dsm.tif -B dem.tif --outfile=ndsm.tif \
  --calc="numpy.where(A-B>1.5, A-B, 0)" \
  --NoData=-9999 --type=Float32
```
参数含义：`A−B` 逐像素算 `DSM−DTM`；`>1.5m` 保留高度值（障碍物），否则记 0；`Float32` 保留小数高度。

> 若直接用 WebODM 的 DSM/DTM，命令改为 `gdal_calc.py -A dsm.tif -B dtm.tif ...`。

### 4.4 障碍物提取与矢量化（PostGIS）

把高度图 `ndsm` 变成障碍物轮廓多边形：

```sql
-- ① 高度阈值二值化 + 多边形化（相邻高像素合并成块）
CREATE TABLE obs_tmp AS
WITH polys AS (
  SELECT (ST_Dump(ST_Polygonize(ST_Union(ST_AsBinary(
           ST_Reclass(rast, 1, '[1.5-9999]:1', '8BUI', 0)
         ))))).geom AS geom
  FROM ndsm
)
SELECT row_number() OVER () AS id, geom FROM polys;

-- ② 取每区域最高高度 + 过滤碎块（<10㎡ 的噪声剔除）
CREATE TABLE obs_cand AS
SELECT t.id, t.geom, round(MAX(p.val)::numeric,2) AS height
FROM obs_tmp t
CROSS JOIN LATERAL (
   SELECT (ST_PixelAsPoints(ST_Clip(r.rast, t.geom))).val AS val
   FROM ndsm r WHERE ST_Intersects(r.rast, t.geom)
) p
GROUP BY t.id, t.geom
HAVING MAX(p.val) > 1.5 AND ST_Area(t.geom) > 10;

-- ③ 类型判定（高度 × 面积，无需正射）
ALTER TABLE obs_cand ADD COLUMN obstacle_type TEXT;
UPDATE obs_cand SET obstacle_type = CASE
  WHEN height > 15 AND ST_Area(geom) > 100 THEN 'BUILDING'   -- 高+大=楼
  WHEN height > 15 THEN 'TOWER_POLE'                          -- 高+小=杆/塔
  WHEN height > 3  THEN 'TALL_OBSTACLE'                       -- 中=树/构筑物
  ELSE 'LOW_OBSTACLE' END;
```

### 4.5 空间数据库入库（PostgreSQL/PostGIS）

**① 栅格入库**（普通 cmd）：
```bat
cd C:\Program Files\PostgreSQL\17\bin
raster2pgsql -s 32649 -I -C -M -t 256x256 D:\cc\drone\ndsm.tif ndsm | psql -U postgres -d gis
```
参数：`-t 256x256` 分块、`-I` 建空间索引、`-C -M` 约束与统计、`-s` 指定投影。

**② 正式障碍物表**：
```sql
CREATE TABLE gis_obstacles (
  id BIGSERIAL PRIMARY KEY,
  obstacle_type TEXT NOT NULL,                 -- 类型：BUILDING/TOWER_POLE/...
  footprint GEOMETRY(Polygon, 32649) NOT NULL, -- 轮廓多边形（规划投影）
  height NUMERIC(10,2),                        -- 相对高度(m)
  bottom_h NUMERIC(10,2),                      -- 底部高程(m)
  top_h NUMERIC(10,2),                         -- 顶部高程(m)
  source TEXT DEFAULT 'WEBODM+QGIS',
  flight_time TIMESTAMPTZ DEFAULT now()        -- 采集/入库时间
);
CREATE INDEX idx_obs_fp ON gis_obstacles USING GIST (footprint);  -- 空间索引
CREATE INDEX idx_obs_typ ON gis_obstacles (obstacle_type);        -- 类型索引

INSERT INTO gis_obstacles (obstacle_type, footprint, height, source)
SELECT obstacle_type, geom, height, 'WEBODM+QGIS' FROM obs_cand;
```

**③ 表内容示意**：
| id | obstacle_type | footprint | height |
|---|---|---|---|
| 1 | BUILDING | 多边形A(某栋楼) | 28.5 |
| 2 | TOWER_POLE | 多边形B(某根杆) | 18.0 |
| 3 | TALL_OBSTACLE | 多边形C(某棵树) | 8.2 |

### 4.6 规划应用（净空/避障）

```sql
-- 航段净空检查：障碍物外扩 5m，检测是否与航段相交
SELECT o.id, o.obstacle_type, o.height,
       ST_3DDistance(p.geom, ST_Force3D(o.footprint)) AS dist
FROM gis_obstacles o, gis_flight_paths p
WHERE p.id = 1001
  AND ST_3DIntersects(ST_Buffer(ST_Force3D(o.footprint), 5), p.geom);
```
- 与 `gis_flight_paths`、`gis_electric_fence`、`gis_astar_3d_flight_plan` 联动，构成"航迹规划 + 净空避障 + 围栏管控"闭环。
- 可按需过滤：只查建筑 `WHERE obstacle_type='BUILDING'`；只查超过某高度 `WHERE height>10`。

### 4.7 三维可视化叠加（Cesium）

**前提**：`gis_obstacles` 导出前统一转 **EPSG:4326**（Cesium 用 WGS84 经纬度），否则与倾斜模型错位。

**三种叠加方式（按需选）**：

**方式 A：GeoJSON + Cesium 前端拉伸白膜（最快）**
```sql
-- 导出（转 4326）
SELECT ST_AsGeoJSON(ST_Transform(footprint,4326))::jsonb
       || jsonb_build_object('height',height,'type',obstacle_type)
FROM gis_obstacles;
```
```js
const viewer = new Cesium.Viewer('cesiumContainer');
viewer.scene.primitives.add(new Cesium.Cesium3DTileset({ url: '.../tileset.json' })); // 倾斜模型

const ds = await Cesium.GeoJsonDataSource.load('obstacles.geojson', { clampToGround: false });
for (let e of ds.entities.values) {
  if (e.polygon) {
    e.polygon.material = Cesium.Color.Yellow.withAlpha(0.6);
    e.polygon.height = 0;
    e.polygon.extrudedHeight = e.properties.height.getValue(); // 拉伸成障碍物高度
  }
}
viewer.dataSources.add(ds);
```

**方式 B：GeoServer 发布**（动态更新、在线查询属性）
- 发布 `gis_obstacles` 为 WMS/WFS，Cesium 用 `WebMapServiceImageryProvider` 或 WFS 加载。

**方式 C：pg2b3dm 转 3D Tiles**（与倾斜模型统一渲染管线）
```bat
pg2b3dm -i "host=localhost user=postgres password=xxx dbname=gis" \
  -t gis_obstacles -c height -o D:\cc\drone\obstacle_tiles --maximumLevel 5
```

## 八、质量控制与运维

1. **坐标系统一**：raster2pgsql 的 `-s`、建表 SRID、Cesium 4326 三处对齐，否则与已有数据失配。
2. **分辨率一致**：DSM/DTM 分辨率必须相同（都用 0.5），否则差分出错。
3. **阈值参数化**：高度阈值 1.5m、面积 10㎡ 按任务动态调；抽样核对。
4. **目视核对**：QGIS 加载 nDSM + DOM，核对漏判（屋顶抹平）、误判（停车场/阴影）。
5. **细小物局限**：细电线杆、稀疏小树易被 DSM 平滑漏判；安全敏感场景用点云路线。
6. **增量更新**：复飞后 `TRUNCATE` 重灌该架次，保留 `flight_time` 版本对比。
7. **索引维护**：大库按 `source`/`flight_time` 分区。
