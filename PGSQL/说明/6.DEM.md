# 6. DEM GeoTIFF 导入与 PostGIS Raster 使用说明

本文整理 DEM GeoTIFF 文件导入 PostgreSQL/PostGIS 的完整流程，包括环境检查、入库命令、参数说明、导入验证、常见问题和后续 SQL 函数调用。

对应脚本：

```text
PGSQL/函数/6.DEM.sql
```

## 2. 前置条件

本机需要能执行以下命令：

```powershell
raster2pgsql
psql
```

如果提示命令不存在，需要确认 PostgreSQL、PostGIS 的 `bin` 目录是否已经加入系统 `PATH`。

目标数据库需要启用 PostGIS 扩展：

```sql
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS postgis_raster;
```

可以用下面命令在目标库中执行：

```powershell
cmd /c "set PGPASSWORD=Ktd@postSQL@2026!@#&& psql -h 192.168.110.6 -p 5432 -U zhuoyi -d ktd_lx_2026gis -c ""CREATE EXTENSION IF NOT EXISTS postgis; CREATE EXTENSION IF NOT EXISTS postgis_raster;"""
```

## 3. 导入前检查

确认 DEM 文件存在：

```powershell
Test-Path "E:\DEM\HENAN.tif"
```

Linux：

```bash
test -f "/data/dem/HENAN.tif" && echo "exists"
```

如果返回 `False`，说明路径或文件名不正确。

检查 DEM 文件能否被 GDAL 识别：

```powershell
gdalinfo "E:\DEM\HENAN.tif"
```

Linux：

```bash
gdalinfo "/data/dem/HENAN.tif"
```

如果 `gdalinfo` 也无法读取，通常是文件损坏、格式不支持或文件路径有问题。

注意：部分 `raster2pgsql` / GDAL 环境对中文路径支持不好。建议 DEM 文件使用纯英文路径，例如：

```text
E:\DEM\HENAN.tif
```

## 4. 正式导入命令

### 4.0 Windows 批处理脚本

项目已提供批处理脚本：

```text
PGSQL/import_today_dem.bat
```

作用：自动查找当天 DEM tif，并导入到 PostGIS Raster。

默认查找目录：

```text
E:\DEM
```

默认按以下顺序查找当天 tif：

```text
E:\DEM\yyyyMMdd.tif
E:\DEM\DEM_yyyyMMdd.tif
E:\DEM\HENAN_yyyyMMdd.tif
```

如果以上文件不存在，会继续查找 `E:\DEM` 下今天修改过的 `.tif` 文件，取最新的一个。

默认导入表名：

```text
public.gis_dem_yyyyMMdd
```

例如 2026 年 7 月 21 日执行时，默认表名为：

```text
public.gis_dem_20260721
```

执行方式：

```cmd
PGSQL\import_today_dem.bat
```

如果当前目录不在项目根目录，可以使用完整路径：

```cmd
E:\CHAJIAN\dajiangData\PGSQL\import_today_dem.bat
```

脚本中的数据库、DEM 目录、SRID、切片大小都在文件开头配置：

```cmd

```

### 4.1 Windows 推荐执行方式

在 Windows 上只打开一个窗口即可：打开 **PowerShell**，然后按下面步骤逐条复制执行。

注意：下面虽然写了 `cmd /c`，但不需要你手动切换到 CMD。`cmd /c` 的作用是让 Windows 的 CMD 程序处理重定向和管道，避免 PowerShell 5 出现大文件管道错误或 SQL 文件编码错误。

第 1 步：删除之前生成过的错误 SQL 文件。

```powershell
Remove-Item "E:\DEM\gis_dem_henan.sql" -ErrorAction SilentlyContinue
```

第 2 步：重新生成 SQL 文件。

```powershell
cmd /c "raster2pgsql -s 4326 -I -C -M -t 256x256 ""E:\DEM\HENAN.tif"" public.gis_dem_henan_v2 > E:\DEM\gis_dem_henan.sql"
```

第 3 步：导入数据库。

```powershell
cmd /c "set PGPASSWORD=Ktd@postSQL@2026!@#&& psql -h 192.168.110.6 -p 5432 -U zhuoyi -d ktd_lx_2026gis -f E:\DEM\gis_dem_henan.sql"
```

第 4 步：验证切片数量。

```powershell
cmd /c "set PGPASSWORD=Ktd@postSQL@2026!@#&& psql -h 192.168.110.6 -p 5432 -U zhuoyi -d ktd_lx_2026gis -c ""SELECT COUNT(*) FROM public.gis_dem_henan_v2;"""
```

第 5 步：查看栅格基本信息。

```powershell
cmd /c "set PGPASSWORD=Ktd@postSQL@2026!@#&& psql -h 192.168.110.6 -p 5432 -U zhuoyi -d ktd_lx_2026gis -c ""SELECT ST_SRID(rast) AS srid, ST_Width(rast) AS width, ST_Height(rast) AS height, ST_NumBands(rast) AS bands FROM public.gis_dem_henan_v2 LIMIT 5;"""
```

如果第 3 步成功，通常会看到 `CREATE TABLE`、`INSERT`、`CREATE INDEX`、`ANALYZE`、`VACUUM` 等输出。

本流程使用新表名：

```text

```

如果确认旧表 `public.gis_dem_henan` 没有创建成功，也可以把上面命令中的 `public.gis_dem_henan_v2` 改回 `public.gis_dem_henan`。

## 5. 参数说明

| 参数 | 说明 |
| --- | --- |
| `-s 4326` | 指定 DEM 坐标系 SRID。`4326` 表示 WGS84 经纬度坐标系。应按 tif 的真实坐标系填写。 |
| `-I` | 为栅格列创建空间索引，提升空间查询性能。 |
| `-C` | 导入后添加栅格约束，例如 SRID、像元大小、范围、波段数量等。 |
| `-M` | 导入完成后执行 `VACUUM ANALYZE`，更新数据库统计信息。 |
| `-t 256x256` | 把 DEM 切片为 `256 x 256` 像元大小的瓦片存储，适合大范围 DEM 查询和局部加载。 |
| `"E:\DEM\HENAN.tif"` | 输入 DEM 文件路径。建议使用英文路径并用双引号包裹。 |
| `public.gis_dem_henan_v2` | 导入后的目标表名。`public` 是 schema，`gis_dem_henan_v2` 是表名。 |
| `psql -h ... -p ... -U ... -d ...` | 连接 PostgreSQL 数据库并执行 `raster2pgsql` 生成的 SQL。 |
| `set PGPASSWORD=...&&` | 在 `cmd /c` 中临时设置数据库密码，避免 `psql` 交互输入密码。 |
| `|` | 管道符，把 `raster2pgsql` 输出的 SQL 传给 `psql` 执行。 |

如果是追加导入到已有表，可以增加 `-a`：

```powershell
cmd /c "set PGPASSWORD=Ktd@postSQL@2026!@#&& raster2pgsql -a -s 4326 -I -C -M -t 256x256 ""E:\DEM\HENAN.tif"" public.gis_dem_henan_v2 | psql -h 192.168.110.6 -p 5432 -U zhuoyi -d ktd_lx_2026gis"
```

首次建表时不要加 `-a`。

## 7. 常见问题

### 7.1 Unable to read raster file

错误示例：

```text
ERROR: Unable to read raster file: E:\卓翼智能\数据\DEM\河南.tif
```

处理方式：

1. 用 `Test-Path` 检查文件是否存在。
2. 用 `gdalinfo` 检查 tif 是否能被 GDAL 读取。
3. 将文件复制到纯英文路径，例如 `E:\DEM\HENAN.tif`。
4. 重新执行导入命令。

### 7.2 表已存在

如果首次导入时目标表已经存在，可以换表名。当前推荐流程已经使用新表：

```text
public.gis_dem_henan_v2
```

如果确认要追加到已有表，使用 `-a`。

### 7.3 PowerShell 管道执行 psql 失败

错误示例：

```text
程序“psql.exe”无法运行: 容量小于当前大小。
参数名: requiredLength
```

这个错误通常不是数据库连接问题，也不是 DEM 文件读取问题。前面已经输出：

```text
Processing 1/1: E:\DEM\HENAN.tif
```

说明 `raster2pgsql` 已经能读取 tif。问题多发生在 Windows PowerShell 管道处理大体量 SQL 输出时。

推荐按 `4.1 Windows 推荐执行方式` 重新生成 SQL 文件并导入。

如果要一条命令直接导入，可以使用：

```powershell
cmd /c "set PGPASSWORD=Ktd@postSQL@2026!@#&& raster2pgsql -s 4326 -I -C -M -t 256x256 ""E:\DEM\HENAN.tif"" public.gis_dem_henan_v2 | psql -h 192.168.110.6 -p 5432 -U zhuoyi -d ktd_lx_2026gis"
```

如果要先生成 SQL 文件，再导入，使用：

```powershell
cmd /c "raster2pgsql -s 4326 -I -C -M -t 256x256 ""E:\DEM\HENAN.tif"" public.gis_dem_henan_v2 > E:\DEM\gis_dem_henan.sql"
```

然后执行：

```powershell
cmd /c "set PGPASSWORD=Ktd@postSQL@2026!@#&& psql -h 192.168.110.6 -p 5432 -U zhuoyi -d ktd_lx_2026gis -f E:\DEM\gis_dem_henan.sql"
```

如果 SQL 文件很大，第二种方式更容易排查问题，也方便重复导入。

注意：不要在 Windows PowerShell 5 中直接使用下面写法生成 SQL 文件：

```powershell
raster2pgsql -s 4326 -I -C -M -t 256x256 "E:\DEM\HENAN.tif" public.gis_dem_henan_v2 > E:\DEM\gis_dem_henan.sql
```

Windows PowerShell 5 的 `>` 可能会把文件保存成 UTF-16 LE，导入时报：

```text
ERROR: character with byte sequence 0xff 0xfe in encoding "GBK" has no equivalent in encoding "UTF8"
```

遇到这个错误时，删除旧的 `E:\DEM\gis_dem_henan.sql`，用 `cmd /c` 方式重新生成。

### 7.4 坐标系不确定

不要盲目写 `-s 4326`。应先通过 `gdalinfo` 查看 DEM 的真实坐标系。

如果 DEM 是米制投影坐标系，应填写对应 EPSG 编码。坡度、坡向等地形分析更适合使用米制投影数据。

## 8. 常用 PostGIS Raster 函数

| 函数 | 用途 |
| --- | --- |
| `ST_Value(rast, band, geom)` | 获取点位所在像元的高程值 |
| `ST_Intersects(rast, geom)` | 判断栅格是否覆盖指定几何 |
| `ST_Clip(rast, band, geom, crop)` | 按面裁剪 DEM |
| `ST_SummaryStatsAgg(rast, band, exclude_nodata)` | 聚合统计高程最小值、最大值、平均值等 |
| `ST_ConvexHull(rast)` | 获取栅格瓦片范围，常用于空间索引 |
| `ST_Slope(rast, band, pixeltype, units)` | 计算坡度 |
| `ST_Aspect(rast, band, pixeltype, units)` | 计算坡向 |
| `ST_HillShade(rast, band, pixeltype, azimuth, altitude)` | 生成阴影地形 |
| `ST_PixelWidth(rast)` | 获取像元宽度 |
| `ST_PixelHeight(rast)` | 获取像元高度 |
| `ST_BandNoDataValue(rast, band)` | 获取 NoData 值 |

## 9. 项目函数

### 9.1 查询经纬度点高程

```sql
public.gis_dem_elevation(
    p_lon double precision,
    p_lat double precision,
    p_srid integer DEFAULT 4326
)
```

示例：

```sql
SELECT public.gis_dem_elevation(116.3913, 39.9075, 4326) AS elevation;
```

### 9.2 按 geometry 点查询高程

```sql
public.gis_dem_elevation_by_point(p_geom geometry)
```

示例：

```sql
SELECT public.gis_dem_elevation_by_point(
    ST_SetSRID(ST_MakePoint(116.3913, 39.9075), 4326)
) AS elevation;
```

### 9.3 面范围高程统计

```sql
public.gis_dem_stats_by_polygon(p_geom geometry)
```

返回字段：

| 字段 | 说明 |
| --- | --- |
| `count` | 有效像元数量 |
| `min` | 最小高程 |
| `max` | 最大高程 |
| `mean` | 平均高程 |
| `stddev` | 标准差 |

示例：

```sql
SELECT *
FROM public.gis_dem_stats_by_polygon(
    ST_GeomFromText(
        'POLYGON((116.38 39.90,116.40 39.90,116.40 39.92,116.38 39.92,116.38 39.90))',
        4326
    )
);
```

### 9.4 线路高程剖面

```sql
public.gis_dem_profile_by_line(
    p_line geometry,
    p_step double precision DEFAULT 10
)
```

返回字段：

| 字段 | 说明 |
| --- | --- |
| `seq` | 采样序号 |
| `distance` | 距线路起点距离 |
| `geom` | 采样点 |
| `elevation` | DEM 高程 |

示例：

```sql
SELECT *
FROM public.gis_dem_profile_by_line(
    ST_GeomFromText('LINESTRING(116.38 39.90,116.40 39.92)', 4326),
    0.001
);
```

注意：`p_step` 使用输入线的坐标单位。如果线路是 `EPSG:4326`，单位是度；如果需要按米采样，应先将线路转换为米制投影坐标系。

## 10. 派生地形数据

脚本中可扩展生成三个派生栅格表：

| 表名 | 说明 |
| --- | --- |
| `public.gis_dem_slope` | 坡度栅格 |
| `public.gis_dem_aspect` | 坡向栅格 |
| `public.gis_dem_hillshade` | 阴影地形栅格 |

示例：

```sql
SELECT ST_Slope(rast, 1, '32BF', 'DEGREES') FROM public.gis_dem_henan_v2;
SELECT ST_Aspect(rast, 1, '32BF', 'DEGREES') FROM public.gis_dem_henan_v2;
SELECT ST_HillShade(rast, 1, '8BUI', 315, 45) FROM public.gis_dem_henan_v2;
```

坡度、坡向计算对坐标单位敏感。生产环境建议使用米制投影 DEM，或先将 DEM 预处理到合适投影后再入库。

## 11. 推荐流程

Windows 推荐只打开 PowerShell，然后逐条执行 `4.1 Windows 推荐执行方式` 中的命令。

```text
1. 将 DEM 放到英文路径：E:\DEM\HENAN.tif
2. 打开 PowerShell，不需要手动切换到 CMD
3. 用 Test-Path 检查文件是否存在
4. 用 gdalinfo 检查 tif 是否可读取，并确认真实 SRID
5. 在目标数据库启用 postgis 和 postgis_raster 扩展
6. 删除旧的 E:\DEM\gis_dem_henan.sql
7. 用 cmd /c 重新生成 E:\DEM\gis_dem_henan.sql
8. 用 cmd /c 调用 psql -f 导入 SQL 文件
9. 查询 COUNT(*)、ST_SRID、ST_Extent 验证入库结果
10. 执行 PGSQL/函数/6.DEM.sql 创建项目查询函数
11. 使用点高程、面统计、线剖面函数进行业务调用
```

关键原则：

- 不要在 PowerShell 5 中直接使用 `raster2pgsql ... | psql ...`。
- 不要在 PowerShell 5 中直接使用 `raster2pgsql ... > E:\DEM\gis_dem_henan.sql`。
- Windows 下统一在 PowerShell 窗口中复制执行文档里的 `cmd /c "..."` 命令。
