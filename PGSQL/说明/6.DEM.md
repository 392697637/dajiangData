# 6. DEM GeoTIFF 在 PostgreSQL/PostGIS 中的使用

本文说明 `tif` 格式 DEM 数据入库到 PostgreSQL/PostGIS 后的使用方式，以及项目中配套的 SQL 函数。对应脚本为：

- `PGSQL/函数/6.DEM.sql`

## 文件内容

| 序号 | 内容 | 说明 |
| --- | --- | --- |
| 1 | 扩展与表结构 | 创建 `postgis`、`postgis_raster` 扩展，定义 `public.gis_dem` 主表 |
| 2 | DEM 入库命令 | 说明 `raster2pgsql` 在 Windows/Linux 下的使用 |
| 3 | DEM 基础检查 | 查看范围、SRID、像元大小、波段、NoData |
| 4 | 点高程函数 | `gis_dem_elevation`、`gis_dem_elevation_by_point` |

| 6 | 线剖面函数 | `gis_dem_profile_by_line` |
| 7 | 派生地形表 | `gis_dem_slope`、`gis_dem_aspect`、`gis_dem_hillshade` |
| 8 | 调用示例 | 点、线、面查询统一放在文档最后 |

## 1. 数据类型

DEM 的 `tif` 通常是 GeoTIFF 栅格数据，入库后建议使用 PostGIS Raster 保存。

默认表：

```sql
public.gis_dem
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rid` | `serial` | 栅格瓦片主键 |
| `rast` | `raster` | DEM 栅格数据 |
| `filename` | `text` | 原始文件名，可选 |
| `created_at` | `timestamp` | 入库时间 |

## 2. 入库方式

先启用扩展：

```sql
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS postgis_raster;
```

使用 `raster2pgsql` 导入 GeoTIFF：

```bash
raster2pgsql -s 4326 -I -C -M -t 256x256 "E:\data\dem.tif" public.gis_dem | psql -h 127.0.0.1 -p 5432 -U postgres -d your_db
```

参数说明：

| 参数 | 说明 |
| --- | --- |
| `-s 4326` | 设置 DEM 坐标系，按实际 tif 的 SRID 修改 |
| `-I` | 创建栅格空间索引 |
| `-C` | 添加栅格约束 |
| `-M` | 入库后执行 `VACUUM ANALYZE` |
| `-t 256x256` | 将大 tif 切片入库，提升局部查询性能 |
| `-a` | 追加数据到已有表，首次建表时不加 |

如果 DEM 原始坐标系不是 `EPSG:4326`，不要强行写 4326，应使用数据真实 SRID。坡度、坡向等地形分析建议使用米制投影坐标系数据。

## 3. 常用 PostGIS Raster 函数

| 函数 | 用途 |
| --- | --- |
| `ST_Value(rast, band, geom)` | 获取点位所在像元的高程值 |
| `ST_Intersects(rast, geom)` | 判断栅格是否覆盖指定几何 |
| `ST_Clip(rast, band, geom, crop)` | 按面裁剪 DEM |
| `ST_SummaryStatsAgg(rast, band, exclude_nodata)` | 聚合统计高程最小值、最大值、平均值等 |
| `ST_ConvexHull(rast)` | 获取栅格瓦片范围，常用于空间索引 |
| `ST_Slope(rast, band, pixeltype, units)` | 计算坡度 |
| `ST_Aspect(rast, band, pixeltype, units)` | 计算坡向 |
| `ST_HillShade(rast, band, pixeltype, azimuth, altitude)` | 生成阴影地形 |
| `ST_PixelWidth(rast)` | 获取像元宽度 |
| `ST_PixelHeight(rast)` | 获取像元高度 |
| `ST_BandNoDataValue(rast, band)` | 获取 NoData 值 |

## 4. 项目函数

### 4.1 查询点位高程

函数：

```sql
public.gis_dem_elevation(
    p_lon double precision,
    p_lat double precision,
    p_srid integer DEFAULT 4326
)
```

说明：

- 入参为点坐标。
- 默认输入坐标系为 `EPSG:4326`。
- 函数会自动转换到 DEM 表的 SRID 后读取第一波段高程。

### 4.2 按 geometry 点查询高程

函数：

```sql
public.gis_dem_elevation_by_point(p_geom geometry)
```

### 4.3 面范围高程统计

函数：

```sql
public.gis_dem_stats_by_polygon(p_geom geometry)
```

返回字段：

| 字段 | 说明 |
| --- | --- |
| `count` | 有效像元数量 |
| `min` | 最小高程 |
| `max` | 最大高程 |
| `mean` | 平均高程 |
| `stddev` | 标准差 |

### 4.4 线路高程剖面

函数：

```sql
public.gis_dem_profile_by_line(
    p_line geometry,
    p_step double precision DEFAULT 10
)
```

返回字段：

| 字段 | 说明 |
| --- | --- |
| `seq` | 采样序号 |
| `distance` | 距线路起点距离 |
| `geom` | 采样点 |
| `elevation` | DEM 高程 |

注意：`p_step` 使用输入线的坐标单位。如果线路是 `EPSG:4326`，单位是度；如果需要按米采样，应先将线路转换为米制投影坐标系。

## 5. 坡度、坡向、阴影地形

脚本中提供三个派生表示例：

| 表名 | 说明 |
| --- | --- |
| `public.gis_dem_slope` | 坡度栅格 |
| `public.gis_dem_aspect` | 坡向栅格 |
| `public.gis_dem_hillshade` | 阴影地形栅格 |

创建方式：

```sql
SELECT ST_Slope(rast, 1, '32BF', 'DEGREES') FROM public.gis_dem;
SELECT ST_Aspect(rast, 1, '32BF', 'DEGREES') FROM public.gis_dem;
SELECT ST_HillShade(rast, 1, '8BUI', 315, 45) FROM public.gis_dem;
```

坡度、坡向计算对坐标单位敏感。生产环境建议使用米制投影 DEM，或先将 DEM 预处理到合适投影后再入库。

## 6. 性能建议

- 大 tif 必须切片入库，推荐 `-t 256x256` 或 `-t 512x512`。
- 必须保留 `ST_ConvexHull(rast)` 的 GIST 索引。
- 查询点高程时先用 `ST_Intersects` 过滤瓦片，再用 `ST_Value` 取值。
- 范围统计只裁剪相交瓦片，避免全表扫描。
- 多份 DEM 可以按区域、分辨率或项目拆表，也可以增加 `dem_name`、`source`、`resolution` 字段管理。

## 7. 典型使用场景

- 无人机航线点位补充地面高程。
- 航线生成时计算相对地形高度。
- 项目区域最高点、最低点、平均高程统计。
- 沿线路生成高程剖面。
- 生成坡度、坡向、阴影地形作为地形分析底图。

## 8. 调用示例

查询经纬度点高程：

```sql
SELECT public.gis_dem_elevation(116.3913, 39.9075, 4326) AS elevation;
```

查询 geometry 点高程：

```sql
SELECT public.gis_dem_elevation_by_point(
    ST_SetSRID(ST_MakePoint(116.3913, 39.9075), 4326)
) AS elevation;
```

查询面范围内高程统计：

```sql
SELECT *
FROM public.gis_dem_stats_by_polygon(
    ST_GeomFromText(
        'POLYGON((116.38 39.90,116.40 39.90,116.40 39.92,116.38 39.92,116.38 39.90))',
        4326
    )
);
```

查询线路高程剖面：

```sql
SELECT *
FROM public.gis_dem_profile_by_line(
    ST_GeomFromText('LINESTRING(116.38 39.90,116.40 39.92)', 4326),
    0.001
);
```
